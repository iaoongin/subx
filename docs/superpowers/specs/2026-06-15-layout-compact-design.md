# UI 布局紧凑化设计方案

## 概述

对 SubX 订阅工作台的 UI 布局进行全面紧凑化优化，减少空白区域，提升信息密度，同时保持良好的视觉层次和用户体验。

## 设计目标

- 减少 30-50% 的垂直空间占用
- 提升信息密度，一屏展示更多内容
- 保持响应式设计，适配桌面端和移动端
- 保持视觉层次清晰，不牺牲可读性

---

## 1. Hero 区域优化

### 桌面端布局（≥ 768px）

**结构：**
- **左侧**：标题 + 描述文字
- **右侧上部**：操作按钮（管理分组、系统配置、退出）
- **右侧下部**：统计数字（订阅、启用、停用）

**改动点：**
- 圆角：28px → 16px
- 内边距：24px → 18px 20px
- 标题字号：clamp(2.2rem, 4vw, 3.6rem) → 22px
- 描述字号：16px → 13px
- 按钮圆角：999px → 12px
- 按钮内边距：10px 14px → 8px 14px
- 移除右下角装饰圆形

### 移动端布局（< 768px）

**结构（竖向排列）：**
1. 标题 + 描述
2. 操作按钮（换行显示，更大触控区域）
3. 统计信息（分割线分隔）

**响应式断点：** 768px

---

## 2. 统计信息优化

### 改动方案

**移除独立统计卡片**，将统计信息整合到 Hero 区域。

**原设计：**
- 3 个独立卡片，占据 80-100px 垂直空间
- 包含 kicker 标签（当前分组、可用状态、需要处理）

**新设计：**
- 在 Hero 右下角显示统计数字
- 格式：`12 订阅 | 8 启用 | 4 停用`
- 颜色区分：启用绿色(#81c784)，停用红色(#ef9a9a)，总数白色

**优势：**
- 节省 80-100px 垂直空间
- 信息整合，减少视觉分散
- 统计信息弱化，不抢夺主标题焦点

---

## 3. 订阅卡片优化

### 标题行

**改动：**
- 状态标签从标题下方移到标题同一行右侧
- 布局：名称 + 类型标签（左）| 状态标签（右）

**HTML 结构：**
```html
<div class="subscription-header">
  <div class="subscription-title">
    <span class="subscription-name">机场名称</span>
    <span class="subscription-type">订阅</span>
  </div>
  <span class="subscription-status">✓ 启用</span>
</div>
```

### 备注

**保留**，保持当前样式。

### URL 区域

**改动：**
- 从换行显示改为单行省略
- 超长 URL 用省略号截断
- 鼠标悬停显示完整内容（title 属性）
- 移除虚线边框，改为简洁实线
- 圆角：18px → 8px
- 内边距：12px → 10px

**CSS：**
```css
.subscription-url {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  border: 1px solid #eee;
  border-radius: 8px;
  padding: 10px;
}
```

### 元数据区域

**改动：**
- 从纵向排列改为横向排列
- 移除背景框
- 改为一行文本：`更新: 2024-01-15 | 流量: 45.2/100 GB | 45%`

**HTML 结构：**
```html
<div class="subscription-meta">
  <span>更新: 2024-01-15</span>
  <span class="meta-separator">|</span>
  <span>流量: 45.2/100 GB</span>
  <span class="meta-usage">45%</span>
</div>
```

### 卡片整体

**改动：**
- 圆角：18px → 14px
- 内边距：14px → 12px
- 按钮高度：34px → 30px
- 按钮圆角：999px → 16px
- 按钮字号：0.84rem → 12px

## 4. 左侧边栏优化

### 当前分组区域

**改动：**
- 移除描述文字"先确认你正在操作哪个订阅集合"
- 卡片圆角：22px → 14px
- 卡片内边距：16px → 14px
- 标题字号：18px → 15px
- 输入框圆角：14px → 10px
- 摘要框圆角：20px → 12px
- 摘要框背景：渐变 → 纯色浅背景
- 操作按钮改为 3 列一行（预览、刷新缓存、刷新流量）
- 按钮高度：40px → 32px
- 按钮圆角：999px → 10px

### 分组内操作区域

**改动：**
- 移除独立卡片，改为分割线分隔
- 移除描述文字"新增订阅会自动绑定到当前分组"
- 标题字号：18px → 14px
- 按钮高度：40px → 36px
- 按钮圆角：999px → 10px

---

## 5. 工具栏优化

### 布局改动

**改动：**
- 从上下布局改为一行排列
- 搜索框、筛选按钮、类型下拉全在一行
- 添加竖线分隔不同功能区域

**结构：**
```
[搜索框] | [全部] [启用] [停用] | [全部类型 ▾]
```

### 元素改动

- 移除"搜索"文字标签
- 外框圆角：20px → 12px
- 外框内边距：12px → 10px
- 搜索框圆角：14px → 10px
- 筛选按钮：去掉背景色填充，改为透明背景
- 按钮内边距：8px 12px → 6px 10px
- 按钮圆角：999px → 8px

---

## 6. 响应式断点总结

| 断点 | Hero 布局 | 工具栏 | 订阅列表 |
|------|----------|--------|----------|
| ≥ 1180px | 左右布局 | 一行排列 | 2 列网格 |
| 768px - 1179px | 左右布局 | 一行排列 | 2 列网格 |
| < 768px | 竖向布局 | 换行 | 1 列 |
